# Описание Saga транзакций системы OrchestrPay
| Транзакция | Описание | Тип | Компенсация
|:-- |:-- |:-- |:-- |
| CREATE_ORDER | В системе создается заказ на основе запроса пользователя. Заказ получает статус "Ожидание оплаты" | Компенсируемая | REMOVE_ORDER |
| PREAUTHORIZE_PAYMENT | Банк блокирует сумму на счёте клиента, но фактическое списание еще не происходит | Компенсируемая | REVERSE_AUTHORIZATION |
| APPROVE_TRANSACTION | Транзакция разрешается antifrod системой, происходит окончательное списание средств (capture) и отправка контрагенту | Необратимая | - |
| REQUEST_MANUAL_REVIEW | Запрашивается ручная проверка подозрительной транзакции | Компенсируемая | CANCEL_MANUAL_REVIEW |
| MANUAL_APPROVE | Транзакция подтверждается вручную, происходит списание средств как при APPROVE_TRANSACTION | Необратимая | - |
| MANUAL_REJECT | Транзакция блокируется в результате ручной проверки | Необратимая | - |
| BLOCK_TRANSACTION | Операция блокируется по результатам проверки antifrod системы | Необратимая | - |
| NOTIFY_SECURITY_DEP | Службе безопасности отправляется оповещение о заблокированной транзакции | Повторяемая | - |
| NOTIFY_CUSTOMER | Пользователю отправляется оповещение об изменении статуса операции | Повторяемая | - |



## Транзакции-компенсации
| Транзакция | Описание | Тип | Компенсация
|:-- |:-- |:-- |:-- |
| REMOVE_ORDER | Заказ удаляется из системы | Повторяемая | - |
| REVERSE_AUTHORIZATION | Снятие блоикровки средств, мгновенный возврат клиенту | Повторяемая | - |
| CANCEL_MANUAL_REVIEW | Отмена запроса на ручную проверку | Повторяемая | - |
